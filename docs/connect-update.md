# Connect, служебные модели и вставка изображений

Ветка: `uiux-polish-3.0.1`. Существующие SKU `vpn`, ссылки `/api/vpn/*`, токены подписок, цены, покупки и история сохраняются. Продуктовые названия в сервисах, магазине, уведомлениях и админке — Connect.

## Где настройки

- Админ → **Служебное**: существующие настройки Whisper, существующие модели TTS, внутренние модели для эмбеддингов, ранжирования и текстовых задач. У внутренних провайдеров есть проверка сохранённой конфигурации и порядок резервирования. Текстовые `internal`-модели могут обслуживать советы сайта; настройка embeddings сама по себе не переводит всю Memory на векторное хранение.
- Админ → **Серверы → VVVion Connect → Установить Connect на VPS**: SSH, протокол, порт, SNI, Reality handshake/Short ID или пути к TLS-сертификату и ключу.

Внутренние модели используют зарезервированные ID `service:<purpose>:<id>` в существующем каталоге. Миграция не нужна. Они исключены из пользовательского каталога, Telegram-селектора, публичного API и его настроек публикации; встроенные чат-запросы к этим ID отклоняются на сервере. Публичные модели сохраняют прежние настройки и до 10 провайдеров. Whisper/TTS остаются на прежних серверных настройках, ключи не переносятся и не перезаписываются обновлением.

## SSH-установка

Только отдельный Debian/Ubuntu VPS, systemd, Python 3, root, amd64/arm64, от 1 ГБ RAM и 3 ГБ свободного диска. Существующий `/opt/vvvion-connect`, конфигурация `/etc/sing-box/config.json`, запущенный sing-box или занятый порт блокируют установку. Проверка получает SSH-отпечаток без передачи пароля, затем подключается только после его подтверждения; IP назначения проверяется и закрепляется на время соединения. Пароль/SSH-ключ не сохраняется в БД и очищается из формы после запуска.

Установка отделена от жизни запроса Vercel: на VPS запускается отдельная systemd-задача. Подготовка и сборка могут занять несколько минут. Данные агента лежат только на VPS в `/opt/vvvion-connect` с правами root/0600. Технический журнал установки доступен через `journalctl -u vvvion-connect-install-<node-id>`; приложение показывает этапы и состояние узла без паролей и ключей.

Закреплены sing-box **v1.14.6** и Go **1.26.11**. Архив Go проверяется по SHA256; модули Go — через публичный checksum database. sing-box собирается из версионированного официального модуля с `with_quic,with_utls,with_v2ray_api`: официальный готовый бинарник не содержит необходимый V2Ray API. Кэш и toolchain после сборки удаляются. Применение конфигурации обязательно проходит `sing-box check`.

VLESS по умолчанию использует Reality с ключами, созданными на VPS. HY2 и обычный VLESS/TLS требуют уже существующие действующие сертификат и ключ для указанного SNI. Проверка TLS клиента не отключается, самоподписанные сертификаты без проверки не выдаются. Внешний firewall провайдера должен пропускать выбранный TCP/UDP-порт; активному UFW добавляется только этот порт. Статистика слушает **только 127.0.0.1:10085**.

На сайте нужен стабильный `VPN_AGENT_TOKEN` либо `BETTER_AUTH_SECRET`. Вновь установленные VPS получают HMAC-ключ, действующий только для их ID; глобальный секрет им не передаётся. Старые агенты с `VPN_AGENT_TOKEN` совместимы. Ротация исходного секрета требует переавторизации агентов.

## Подписки и счётчики

Агент каждые 20 секунд получает разрешённые личные ключи сайта, применяет именованных пользователей sing-box и передаёт реальные V2Ray-счётчики. Перед включением нового пользователя устанавливается нулевой baseline. Данные разных устройств суммируются по аккаунту; повторный опрос не добавляет те же байты повторно. Абсолютные итоги сохраняются на VPS атомарно, учитывают смену systemd InvocationID и сброс счётчиков. Сервер принимает отчёты только для пользователей, которым этот узел выдавал ключи.

Просроченный, заблокированный или исчерпавший квоту пользователь удаляется при следующей синхронизации; изменение набора клиентов перезапускает управляемый sing-box и завершает прежние соединения. При недоступности панели более 5 минут агент очищает список клиентов. Неизвестные/непрочитанные счётчики не заменяются нулями. Общего ключа у новых управляемых серверов нет.

Новый узел скрыт из подписок до успешного применения клиентов. Первое сообщение `provisioned` включает его, но повторное сообщение никогда не отменяет последующее ручное скрытие или обслуживание администратором.

## Изображения и проверка

Общий обработчик принимает Clipboard `files` и `items`, не дублируя один bitmap. В ИИ-чате и Круге поддерживаются Ctrl+V/системная вставка. На телефоне команда «Из буфера» находится в меню вложений. Clipboard API вызывается только нажатием; если браузер не даёт доступ, остаётся системная вставка. Внешние URL из HTML буфера автоматически не скачиваются.

Браузером проверены реальные компоненты: Ctrl+V в ИИ и Круге, кнопка буфера, мобильное меню 390 px, формы внутренних моделей, переключение VLESS/HY2 и светлая/тёмная темы. Использованы локальные тестовые экраны, не пользовательские диалоги; тестовые маршруты удаляются перед публикацией.

Настоящим собранным sing-box проверен `check` для VLESS/Reality, VLESS/TLS и HY2/TLS. Unit/integration-тесты покрывают счётчики, baseline, replay, область ключа VPS, настройки и изоляцию служебных моделей. Полный сетевой roundtrip в рабочей среде ограничен запретом netlink-сокетов. На реальном VPS установка и соединение в этом изменении не проверялись: конкретный тестовый сервер и его доступ не предоставлены. Доступен opt-in тест: `SING_BOX_BIN=/path/to/sing-box python3 scripts/connect/test_agent.py`.
