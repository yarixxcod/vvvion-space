# Откат поддержки и модерации

Миграция `migrations/0056_support.sql` только добавляет таблицы и колонку `posts.hidden_at`.
Журнал попыток `chat_attempts` не меняется.

Откат схемы — `migrations/down/0056_support.sql`:

- удаляет только новые таблицы поддержки, жалоб, санкций, апелляций, шаблонов, событий и уведомлений;
- снимает колонку `posts.hidden_at`;
- не удаляет строки `posts`, баны в `members` и журнал `chat_attempts`.

После отката кода скройте записи вручную нельзя: колонки уже нет, записи снова видны.
Блокировки аккаунтов, выставленные через `members.banned_at`, остаются. Снять их можно в админке, вкладка «Участники».

Код выкатывается веткой `feature/support-moderation-center` и линией `uiux-polish-3.0.1`.
В `main` этот набор не вливается. Откат выкладки — промоут предыдущего production deployment в Vercel, без `git push --force`.
