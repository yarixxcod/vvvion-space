# Стикеры Космокота и новогодний набор

Основной каталог и доступные коды: `src/lib/stickers.ts`. Не дублировать список в промптах вручную. `stickerReplyGuide` собирает список по реальной дате запроса, часовому поясу браузера и последней просьбе пользователя. Старые клиенты без часового пояса используют UTC.

Автоматический новогодний сезон: 15 декабря — 10 января включительно, ежегодно. В другое время ИИ может отправить новогодний стикер только по прямой просьбе. Пользователь выбирает и отправляет любые наборы круглый год. Исторические сообщения не скрываются при смене сезона. Выключение стикеров ИИ имеет приоритет над сезоном и просьбой.

Известные ошибочные названия нормализуются: например `cosmo-cool` → `cosmo-yes`, `cosmo-list` → `cosmo-think`. Регистр и безопасные разделители нормализуются. Неизвестная команда удаляется без подстановки случайной эмоции. `StickerTextGate` задерживает только потенциальную команду, а не весь ответ, и поддерживает произвольное разбиение по дельтам; обычный Markdown и `[[like]]` сохраняются. Сохранение ответа в облако применяет ту же политику. Каталог из 112 позиций проверяется на наличие локальных файлов.

Новый набор: `public/stickers/winter-{hello,tree,gift,snowman,cocoa,fireworks,sleep,sled}-v1.webp`. Восемь оригинальных прозрачных иллюстраций, оптимизированные WebP 512×512 (65–85 КБ каждый); исходные генерации 1254×1254. Основные старые ассеты не перезаписываются.

Художественный промпт: один самостоятельный стикер на прозрачном фоне; тот же тёмно-фиолетовый пушистый космокот с изумрудными глазами и звёздным ошейником, объёмная цифровая отрисовка, чёткая белая обводка, лавандовые/красные/золотые акценты, полный силуэт, без текста и цифр. Сюжеты: приветствие в шапке Санты; объятие ёлочки; кот в коробке подарка; снеговик; какао; бенгальский огонь; сон рядом с подарком; санки. Созданы генерацией изображений по референсу существующего `cosmo-hello-v1.webp`; сжатие сохраняет альфа-канал.

Проверки: `npm run typecheck`, `npm test`, `npm run lint`, `npm run build:web`. Дополнительные сезонные и потоковые сценарии — `src/lib/stickers.test.ts`; целостность всего каталога — `src/lib/social/message-likes.test.ts`.
