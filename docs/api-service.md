# Публичный API VVVion

Это шлюз к тем же моделям, что уже стоят в каталоге. Отдельного списка моделей нет и своего инференса тоже нет. В запрос не подмешиваются системный промпт каталога, персоны, память и агент: внешний клиент присылает свой текст как есть.

Пока сервис выключен (`api_settings.enabled = false`), обычный запрос на `/v1` отвечает `503`. Админ аккаунта проходит этот замок, чтобы проверить ключ. Плитка «API» в «Сервисах» скрыта у всех, кроме админов.

## Что умеет

- `GET /v1/models`
- `POST /v1/chat/completions` — обычный ответ и поток
- `POST /v1/messages` и `POST /v1/messages/count_tokens` (подсчёт токенов — оценка по длине текста)
- `POST /v1/images/generations` — только `b64_json`, одна картинка, на Диск не сохраняется
- `POST /v1/responses` — урезанный режим без памяти. `previous_response_id` и `store: true` отклоняются. `GET /v1/responses/{id}` не реализован

Не поддерживаются эмбеддинги, аудио, файлы, батчи и Assistants.

## Ключи и доступ

Ключ выглядит как `vvvion-sk-` и 43 символа. В базе лежит только sha256. Пользователь видит секрет один раз. Одновременно не больше `max_keys` активных ключей (0 — без потолка) и не больше 10 созданий в час.

Каждый запрос заново проверяет: сервис включён или это админ, ключ, бан, Premium, минутный и суточные лимиты. Сессия сайта на `/v1` не принимается. Ключ не открывает Диск, банк, чат и профиль.

Дневной лимит чата и лимит API не связаны. Небольшой перебор суточных токенов допустим: лимит сравнивается с уже записанной суммой, токены текущего ответа известны только в конце.

По умолчанию: сервис выключен, запросов и токенов в сутки без потолка, 20 картинок в сутки, 30 запросов в минуту, до 16384 токенов в ответе, 5 ключей.

## Ограничения площадки

Тело запроса не больше 4 МБ. Обычный ответ ждёт до 90 секунд, поток и картинка — до 240. На Vercel у функции лимит около 300 секунд. Тексты промптов и ответов не пишутся ни в таблицы, ни в логи.

## Как добавить адрес api

1. DNS: CNAME `api` на Vercel.
2. Добавить `api.vvvion.space` в проект как Production-домен и дождаться Valid.
3. В админке открыть раздел API и включить сервис.
4. Проверить: `curl -i https://api.vvvion.space/v1/models` без ключа должен вернуть JSON `401`, а не HTML. Тот же путь уже работает на `https://vvvion.space/v1`.

Редирект корня `api.vvvion.space` на сайт в `vercel.json` не добавлялся: существующие заголовки и cron лучше не трогать.

## Как отозвать ключи

Пользователь отзывает свой ключ в Сервисах → API. Админ в разделе API может отозвать все ключи пользователя по его id. Строка ключа остаётся, секрет по ней больше не проходит.

## Дымовой прогон

`API_BASE` и `API_KEY` задаются в окружении:

```
API_BASE=https://vvvion.space/v1 API_KEY=vvvion-sk-… node scripts/api-smoke.mjs
```

Картинки пропускаются, если не задать `API_SMOKE_IMAGE=1`. Скрипт не входит в `npm test` и не печатает ключ.

Модели чата публикуются по одному стабильному ID из каталога, как в ИИ-чате (например `DeepSeek`). Внутренние имена провайдеров не создают отдельные модели. Запрос начинает с первого провайдера и переходит к следующим при ошибке до выдачи пригодного ответа; неоднозначные старые имена провайдеров отклоняются.
