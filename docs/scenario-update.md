# Режим «Сценарий» и Markdown чата

- Телефон: «+» → «Сценарий»; выключение также крестиком на чипе.
- ПК: кнопка с хлопушкой в панели инструментов сообщения.
- Выбор хранится локально, по умолчанию выключен. Повтор ответа использует режим исходного сообщения. Сеть, рассуждение и уточняющие вопросы совместимы; генерация картинок исключает сценарий. Голосовые обращения и стикеры отправляются без него.
- Полный сценарный промпт хранится только в `scenario-prompt.server.ts`. Клиент передаёт boolean. При включении сервер защищает ядро и сценарный слой, а низкоприоритетный контекст сокращает с конца до общего лимита 56 000 символов.
- Все обычные fenced-блоки имеют кнопку копирования исходного текста; текстовые блоки не интерпретируют Markdown. Специальные calc/ASCII остаются прежними. «Скопировать всё» у ответа убирает разметку прозы и сохраняет содержимое кода.
- Потоковая обработка завершает незакрытые fences и выделения только в растущем хвосте. Таблицы и свободные списки сохраняют структуру.
- HTML остаётся текстом; ссылки разрешены только HTTP(S), открываются с nofollow/noopener/noreferrer.

Проверки: unit-тесты строгого флага, защиты системного промпта, plaintext и streaming; SSR реального Markdown-компонента для карточек/GFM/XSS. Браузерная проверка композера и Markdown на ПК и в 390px iframe, сохранения режима, взаимоисключения с картинкой, копирования и ru/en/kk.
