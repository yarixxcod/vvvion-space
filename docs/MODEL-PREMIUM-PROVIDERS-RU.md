# Модели, подписка и провайдеры

Администрирование → Модели → открыть модель:
- до 10 провайдеров; первый — основной, остальные резервные;
- стрелки меняют приоритет, идентификатор провайдера сохраняется;
- «Только VVVion Premium» помечает модель и ограничивает доступ действующей подпиской.

По умолчанию все существующие модели остаются бесплатными. Признак доступен в публичном каталоге, но ключи провайдеров там не публикуются. В селекторе — корона, лавандовая карточка и замок без подписки; нажатие ведёт к подписке. Проверка доступа обязательна на сервере: веб-чат, звонок, Telegram и публичный API.

Администрирование → Статистика → «Куда уходят запросы»: модель, провайдер, хост, upstream model ID, канал (чат/звонок, API, Telegram), попытки, HTTP 2xx, ошибки и среднее время до заголовков. Повторы параметров, резервные попытки и вызовы модели между инструментами учитываются как отдельные реальные HTTP-попытки. HTTP 2xx не гарантирует завершения стрима или пригодность ответа.

Новая статистика собирается с внедрения; прежняя история не распределяется задним числом. Хранятся часовые счётчики без текстов, ключей, ответов или идентификаторов пользователей. При сбое аналитики ответ продолжает работать. Миграция 0064 расширяет проверку slot, добавляет признак и стабильный ID, создаёт таблицу счётчиков; покупки, балансы и история чатов не изменяются.
