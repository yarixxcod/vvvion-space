# Перенос VVVion на свой сервер

Раздел «Бэкап» в админке копирует сайт на пустой сервер Ubuntu или Debian. Сайт на Vercel только проверяет SSH, кладёт агент и принимает отчёты. Сборку, дамп базы и зеркало файлов делает агент на целевом сервере. Функция Vercel не держит соединение на всё время переноса.

## Что копируется

- Код репозитория `yarixxcod/vvvion-space` на закреплённом коммите. Для git-источника агент сверяет `git rev-parse HEAD` с этим коммитом. Чужие «ускорители» GitHub по умолчанию не используются: подмена кода опаснее, чем медленная загрузка. Свой GitLab, Codeberg или Gitea можно добавить в зеркала.
- Настройки из разрешённого списка имён. `DATABASE_URL` сайта не копируется: на новом сервере своя база в Docker. Строка источника передаётся отдельно как `BACKUP_SOURCE_DATABASE_URL` и удаляется после дампа.
- Пользователи, сессии и файлы диска — вместе с дампом. Сессии останутся действительными только если домен и `BETTER_AUTH_URL` те же и включён HTTPS.
- Зеркало Мегадиска в `/var/lib/vvvion-mirror`. Сайт по-прежнему читает файлы с прежних узлов, пока вы сами не переключите узлы.

`npm ci` проверяет `package-lock.json`, поэтому зеркало npm не может подменить пакет: несовпадение integrity обрывает сборку. `npm install` для этого пути не используется.

## Безопасность

Пароль и ключ SSH живут только в одном запросе и не пишутся в базу, журнал и ответы. Токен задания в базе хранится как SHA-256, агенту отдаётся один раз и живёт 72 часа. Журнал чистится от секретов и на агенте, и на сайте. Одновременно идёт одно задание. Без отпечатка SSH и слова «ПЕРЕНЕСТИ» запуск закрыт.

## Как смотреть журнал

```
journalctl -u vvvion-migrate
tail -f /opt/vvvion/.migrate/agent.log
```

Состояние лежит в `/opt/vvvion/.migrate/state.json`. Повторный запуск службы пропускает готовые этапы и докачивает файлы. Повторить этап можно кнопкой в админке или командой агента `retry:<этап>`.

## Домен

1. Проверьте `/api/health` на новом сервере.
2. Поставьте A-запись домена на IP сервера и включите HTTPS.
3. Только потом останавливайте старую копию. Две живые копии расходятся: платежи, письма и продления выполнятся дважды, если включить расписание на обеих. На копии расписание выключено, пока вы не нажмёте «Включить расписание».

Перед досинхронизацией базы остановите изменения на старом сайте. Отдельного режима обслуживания в проекте нет: это предупреждение, не переключатель.

## Очистка

Кнопка «Очистить сервер» снова просит SSH и слово «УДАЛИТЬ». Она выполняет `docker compose down -v` только в `/opt/vvvion/src`, затем удаляет `/opt/vvvion`, службу `vvvion-migrate` и `/var/lib/vvvion-mirror`. Docker, Node и каталоги вне этих путей не трогаются.

## Что не входит в эту версию

Сделать новый сервер узлом Мегадиска, автоматический HTTPS через Caddy и регулярный дамп по расписанию не включены: это отдельные службы и их нельзя запускать без отдельного подтверждения. Зеркало файлов лежит рядом с сайтом и само по себе в работу сайта не включается.
