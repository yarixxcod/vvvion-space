# VVVION Space — «Круг»: аудит дизайна и патч для Cursor

## Правила для Cursor
- Сначала найди код по строкам-подсказкам через `rg` (бандлы минифицированы, имена функций случайные: ищи по строкам из таблиц), прочитай и только потом меняй.
- Не выдумывай. Не нашёл подсказку — остановись и напиши, что именно не нашёл. Пункты **[проверить]** сначала исследуй, потом чини.
- Одна задача — один коммит: `circle-ux: <номер> <кратко>`. После каждой: `build`, `lint`, критерии приёмки.
- Тёмная и светлая темы обязательны. Цвета только из токенов (`--bg --elev --subtle --fg --muted --faint --line --line-strong --accent --accent-fg`). Новых цветов не вводить.
- Каждый пункт помечен **«сайт»** (делает Cursor) или **«APK (сделает Гик)»** (код приложения; Cursor его не трогает, но делает сайтовую половину и пишет, что ждёт от приложения). Всё про `VvvionApp` оборачивай в `isApp()` / `window.VvvionApp?.`.
- **Не дублируем прошлые файлы, только ссылки:**
  - `chat-ux/CURSOR-CHAT-UX-2-RU.md` («чат-2»): раздел 7 — токены (сетка 4 px, шкала отступов, радиусы, тап-цели, контраст), раздел 2 — `BottomSheet` через портал, раздел 5 A-1 — стек слоёв `pushBackLayer` / `__vvvionHandleBack`, раздел 6.0–6.2 — правила жестов, `useSwipe`, `useLongPress`, пороги, M-P0-3 — `overscroll-behavior-x`.
  - `v2/CURSOR-APP-BRIDGE-RU.md` (мост 2.8.0): `VvvionApp`, `haptic(type)`, классы `vv-app / vv-lowend / vv-reduce-motion`, сайтовый pull-to-refresh, push.
- Круг сейчас **не** использует хуки из чат-2 (их там ещё нет, если Cursor ещё не внедрил чат-2). Если `useSwipe`, `BottomSheet` и `pushBackLayer` уже есть в коде — используй их; если нет — сначала внедри их по чат-2, потом применяй этот файл.
- Жесты — pointer events, `{passive:true}`, `touch-action: pan-y` на жестовых контейнерах; `prefers-reduced-motion` и `html.vv-reduce-motion` уважать.

## 0. Что такое «Круг» на сайте
**Главный объект аудита — оверлей «Круг»** («суперприложение» внутри vvvion.space), открывается кнопкой «Круг» в шапке чата (обёртка `.circle-glow` вокруг кнопки). Это правая панель поверх чата на всю высоту: на ≤ 767 px — на весь экран, на 768–1279 — до 52rem, на ≥ 1280 — `calc(100% - 18.5rem)` (чат-сайдбар 296 px остаётся слева). Адрес — `/?place=<раздел>` (**по коду**: класс `fixed inset-y-0 right-0 z-40 … md:w-[min(100%,52rem)] xl:w-[calc(100%-18.5rem)]`; **измерено** на 390, 768, 1440).

**7 разделов** (вкладки, `?place=…`):
| Вкладка | place | Что внутри (**измерено**) |
|---|---|---|
| Сообщения | `chat` | поиск друга по имени/почте, «+ новая группа», «Диалоги», «Друзья»; справа — «Напишите другу» (на ПК/планшете); внизу «совет дня» (1/5) |
| Лента | `feed` | поле «Что нового?» (0/500), «Вложить», «Из круга», «Опубликовать»; записи людей с картинками/треками, ♡ 💬 ⤴ |
| Развлечения | `play` | «Читальня» (EPUB/FB2/TXT/PDF, поиск, «На полку»), «Смотрельня» (YouTube/Rutube/VK), «Игры» |
| Сервисы | `services` | Погода, Новости, Курсы, VPN, Загрузчик — крупные карточки с иллюстрациями |
| Диск | `disk` | квота «0 из 100 МБ», «Скачать всё архивом», «Общая ссылка», папки, «Мегадиск» |
| Банк | `bank` | «Вубли», карта (переворачивается по тапу), «Забрать 100» с чекбоксом «Я не робот», «Перевести / Кредит / Номер», приглашения |
| Магазин | `shop` | VVVION Premium, VPN, Мегадиск, «Сутки подлиннее», места на диске (покупки не нажимались) |

(+ «Админ» только для админа — не смотрел.)

**Другие кандидаты на слово «Круг» (по запросу пользователя «дизайны круга»):**
- Кнопка «Круг» в шапке чата — `.circle-glow` (переливающаяся окантовка, 83×44 px) с бейджем непрочитанного. Разобрана внутри разделов 4–5 (мобильная и приложение).
- **Публичные SEO-страницы `/c/<раздел>`** для гостей (`/c/feed`, `/c/play`, `/c/services` …: короткий текст + «Войти и открыть»). Это не интерфейс Круга; в аудит не вошли, кроме одного гостевого скриншота `shots/m390-50-guest-c-feed.png` (**не разбирал подробно**).
- Анимированная «метка/лицо» ассистента (`.mface`, `.mark`) относится к чату, не к Кругу.

## 2. Сквозные баги (P0)

### C-P0-1. Раздел Круга не входит в историю: «Назад» и свайп вправо уводят мимо Круга — **сайт** (+ **APK**, раздел 5)
**Что измерено.** Открытие Круга и переключение вкладок меняют только `?place=` без записи в историю: `history.length` не растёт при открытии Круга (2 → 2); после перехода на «Магазин» одно «Назад» сразу ушло на `about:blank` (то есть вкладки тоже не оставляют записей). Поэтому «Назад» в браузере выходит из Круга **на то, что было до сайта** (в тесте это `about:blank`, потому что вкладка так стартовала — в реальной жизни это предыдущая страница или выход из сайта); возврата в чат при этом не происходит. Горизонтальный свайп вправо в Круге (CDP) привёл к тому же уходу из сайта (`overscroll-behavior-x` у `html`/`body` = `auto`, см. чат-2 M-P0-3). **В приложении** у WebView нет истории для «Назад», поэтому системная «Назад» из Круга, скорее всего, не вернёт в чат (у WebView нет записей истории; фактическое поведение в APK **не проверено**; см. мост 2.8.0, пункт 9). Единственный путь из Круга — кнопка «К чату».
**Как чинить.** Подсказки: `rg -n "place=" index-*.js routes-*.js messenger-*.js`, `rg -n "Закрыть круг"`.
1. Открытие Круга — `history.pushState({vvCircle:1}, '', '/?place=' + tab)`; **переключение вкладок — `replaceState`** (чтобы «Назад» уходил из Круга, а не листал 7 вкладок); подэкраны внутри раздела (экран «Новая группа», диалог, книга, чтение) — `pushState`.
2. `popstate`: закрывает верхний слой (подэкран → Круг → чат). Закрывалки регистрировать в стеке из **чат-2 A-1** (`pushBackLayer(close)`); добавить сюда слой «Круг» и слои подэкранов. Для нативной кнопки (`__vvvionHandleBack`) ничего нового: тот же стек.
3. `html.vv-app, html.vv-standalone, aside[data-circle]{overscroll-behavior-x:none}` и `overscroll-behavior:contain` на панели Круга (в обычной вкладке браузерный «назад» не отключать — см. чат-2 6.0).
```ts
// src/features/circle/useCircleHistory.ts
export function openCircle(tab: Tab, close: () => void) {
  history.pushState({ vvCircle: 1 }, '', `/?place=${tab}`);
  const off = pushBackLayer(() => history.back());          // нативная «Назад» → history.back()
  const onPop = () => { if (!(history.state && history.state.vvCircle)) { close(); } };
  addEventListener('popstate', onPop);
  return () => { removeEventListener('popstate', onPop); off(); };
}
export const switchTab = (tab: Tab) => history.replaceState({ vvCircle: 1 }, '', `/?place=${tab}`);
```
**Приёмка.** Чат → Круг → Лента → Банк → «Назад» → чат (а не уход с сайта); из экрана «Новая группа» «Назад» → список; прямой переход на `/?place=feed` и «Назад» → закрытие Круга и чат; в приложении (после APK-части) системная «Назад» ведёт так же; свайп вправо в `vv-app` не выходит из сайта.

### C-P0-2. На ПК нет ограничения ширины: контент растягивается на весь экран — **сайт**
**Что измерено** (таблица выше). Лента 94 → 124 → 146 → 211 знаков в строке при 768 → 1280 → 1440 → 1920, текст 14/20 растянут на 1071–1551 px; картинка записи 1071×448 / 1551×448; карта банка до 1591×1003 (больше самого экрана на 1080 по высоте); обложки книг до 520×781 (3 колонки на 1440, 2 на 1920 по ширине). Раздел «Сервисы»: заголовок ограничен `max-w-md` (448), но карточки растут вместе с экраном (516 / 756 px шириной). Диск и Магазин — одна колонка на 1085–1565 px.
**Как чинить.** Подсказка: в каждом разделе корневой контейнер без `max-w` (ищи корневые `div` разделов в `circle-*.js`, `feed-*.js`, `shelf-*.js` (точные классы не проверял)). Единая обёртка:
```tsx
// src/features/circle/Column.tsx
export function Column({ w = 'md', children }: { w?: 'sm' | 'md' | 'lg'; children: React.ReactNode }) {
  const max = { sm: 'max-w-[42rem]', md: 'max-w-[45rem]', lg: 'max-w-[60rem]' }[w];   // 672 / 720 / 960
  return <div className={`mx-auto w-full ${max} px-4 md:px-6`}>{children}</div>;
}
```
| Раздел | Обёртка | Детали |
|---|---|---|
| Лента | `w="sm"` (672) | текст записи `max-w-[68ch]`; картинка `max-h-[min(70dvh,560px)] w-auto max-w-full rounded-2xl object-contain`; поле «Что нового?» — внутри колонки |
| Диск, Магазин | `w="md"` (720) | карточки в одну колонку, как сейчас |
| Банк | `w="md"` | карта: `mx-auto w-full max-w-[26rem]` (416 px, `aspect-[1.586/1]`), блок «Перевести/Кредит/Номер» под ней |
| Сервисы | `w="lg"` (960) | сетка `sm:grid-cols-2` остаётся; на 1440 карточка ≈ 468 вместо 516 |
| Развлечения | `w="lg"` | сетка книг `grid-cols-[repeat(auto-fill,minmax(160px,1fr))]` вместо фиксированного числа колонок; обложка не шире 220 px |
| Сообщения | см. C-P1-3 | двухпанельный вид |
Границы между колонкой и краями остаются пустыми (фон `--bg`); панель/шапка Круга по-прежнему на всю ширину.
**Приёмка.** 1280–1920: в Ленте 66–74 знака в строке; карта банка ≤ 416 px; обложка ≤ 220 px; ничего не вылезает; на ≤ 768 вид не изменился (колонка = 100%).

### C-P0-3. Фон за Кругом не изолирован: фокус, анимации, Esc — **сайт**
**Что измерено.**
- **Фокус:** на 390 px первый `Tab` после загрузки `/?place=feed` попадает **в скрытый под Кругом чат** («Показать историю» → «Новый чат» → «Поделиться диалогом» → «Круг» → …), а не в Круг. На 1440 первый `Tab` идёт в чат-сайдбар («Новый чат», поиск, «Удалить все», строки истории, «Переименовать/Скачать/Удалить» каждого чата) — он остаётся виден слева, но к Кругу фокус доходит только после всех кнопок сайдбара истории (в замере первые 8 остановок — только сайдбар).
- **Esc:** при фокусе на `body` Круг **не закрывается** (проверял только так; с фокусом внутри Круга не проверял).
- **Анимации скрытого чата** продолжают работать пока Круг открыт: `drift` (2 фоновые «орбы»), `glow-slide` (кнопка «Круг»), `face-blink`/`face-glance`, `signal-wave` — **5 активных анимаций на 390 px и 11 на 768+** (измерено через `document.getAnimations()`).
- Вкладки — обычные `<button>` без `role="tab"`, `aria-selected`, без стрелок ←/→ (проверено: на фокусе «Лента» `ArrowRight` не двигает фокус).
**Как чинить.**
```tsx
// Круг как диалог
<aside role="dialog" aria-modal={overlayMode} aria-label="Круг" data-circle ...>
  <div role="tablist" aria-label="Разделы круга" className="snap-row flex gap-1 px-3 pt-2 pb-2">
    {tabs.map(t => <button role="tab" id={`tab-${t.id}`} aria-selected={t.id===active} aria-controls="circle-panel"
        tabIndex={t.id===active ? 0 : -1} onKeyDown={onTabKey} ...>{t.label}</button>)}
  </div>
  <div role="tabpanel" id="circle-panel" aria-labelledby={`tab-${active}`}>…</div>
</aside>
```
- Пока Круг открыт: `inert` на основной контейнер чата (`main`) — на ≥ 1280 сайдбар чата тоже `inert`, а скрытие его — см. C-P1-1; при закрытии вернуть фокус на кнопку «Круг».
- `onTabKey`: ←/→ (с зацикливанием по краям нет), `Home`/`End`, активная вкладка `scrollIntoView({inline:'center',block:'nearest'})`.
- Esc: слой «Круг» в стек `pushBackLayer` (чат-2 A-1/P0-1); `Esc` на любом элементе внутри Круга закрывает верхний слой.
- Пауза скрытого: `html.circle-open .ambient *, html.circle-open .mface *, html.circle-open .circle-glow, html.circle-open .circle-glow *{animation-play-state:paused!important}` (класс ставить при открытии). `prefers-reduced-motion`/`vv-lowend` уже отключают `circle-glow`, `mark-*`, `orb` — оставить.
**Приёмка.** Круг открыт → первый `Tab` попадает в «К чату»/вкладки; `Esc` закрывает Круг (в т. ч. из поля поиска); стрелки переключают вкладки; `document.getAnimations()` для скрытого чата — `paused`; после закрытия фокус возвращается на «Круг».

### C-M-5. Диалог: Enter, ширина пузырей, нет long-press — **по коду** (экран не открывался)

**Как чинить.**
```ts
const isTouch = matchMedia('(pointer:coarse)').matches;
onKeyDown={e => {
  if (e.nativeEvent.isComposing || e.keyCode === 229) return;                 // IME
  if (e.key === 'Enter' && !e.shiftKey && !isTouch) { e.preventDefault(); send(); }
}}
```
Пузырь: `max-w-[min(85%,32rem)]`, `px-3 py-2` (12/8), `text-base leading-6`, радиус 20 (`--r-lg`+4 → привести к 16 или 24; выбрать 24 для «хвоста» `rounded-br-md` → `rounded-br-lg`). **Приёмка.** **[проверить после реализации на устройстве]**: на телефоне Enter переносит строку; на ПК Enter/Shift+Enter как раньше; пузырь ≥ 16 px; long-press открывает sheet.

**Эффект на реальном телефоне — не проверено** (в Playwright/headless кадры привязаны к vsync, результат «60 fps при троттлинге 6×» **ничего не доказывает**, не опирайтесь на него).

### CA-3. Deep links и открытие из уведомлений — **APK (сделает Гик)** + **сайт**
Сайт знает адреса `/messages/$id`, `/c/$section`, `/r/$code` (инвайт), `/p|d|b|card|s/$token`. **APK:** `intent-filter` (`android:autoVerify`) на `https://vvvion.space/messages/*`, `/c/*`, `/r/*`; клик по уведомлению (`url` из `notify`, мост) открывает WebView на этот адрес, а не пересоздаёт приложение. **Сайт:** `/messages/<id>` и `/r/<code>` должны открывать Круг на нужном подэкране (`pushState`, C-P0-1), `/c/<section>` для залогиненного — Круг на разделе (по коду так и есть). **[проверить на устройстве]**.

### CA-4. Файлы, камера, голос — **APK (сделает Гик)**
Круг использует: «Вложить» (Лента), «+ файл» (Диск, до 25 МБ книги в Читальне), голосовые (диалоги, «Голосовой ввод»), «Скачать всё архивом». В WebView это требует: `WebChromeClient.onShowFileChooser` (выбор файла/камеры), `onPermissionRequest`+`RECORD_AUDIO` для записи голоса, `DownloadListener` → `DownloadManager`/MediaStore для архива и книг. **Не проверено** (нет WebView под рукой) — Гик должен подтвердить, что всё это уже работает, иначе кнопки в Круге молча не срабатывают.

### CA-5. Ролики и внешние ссылки («Смотрельня») — **APK (сделает Гик)**
YouTube/Rutube/VK-плееры: `WebChromeClient.onShowCustomView` для полноэкранного режима, `shouldOverrideUrlLoading` — внешние домены открывать во внешнем браузере (`Intent.ACTION_VIEW`), встроенные плееры не ломать. **Не проверено.**

### CA-6. Вибрация в Круге — **сайт** (типы — мост 2.8.0, чат-2 A-5)

## 6. Свайпы и жесты в Круге

### 6.0. Правила
Применяются **правила из чат-2, раздел 6.0** целиком (старт ≥ 12 px, |dx| > 1.5·|dy|, зона от края ≥ 24 px, исключения `.scroll-x, pre, .snap-row, input, textarea, [data-no-swipe]`, пороги 35–40% / 0.5 px/мс, `pointercancel`, reduced-motion, гейт `vv-app`/standalone для горизонтальных жестов в обычной вкладке не включаются). ### 6.2. Реализация (только то, что новое; `useSwipe`/`useLongPress` — из чат-2 6.2)
```tsx
// Смена раздела свайпом (CG1). Работает поверх useSwipe из чат-2.
function SectionSwipe({ tabs, active, onChange, children }: { tabs: Tab[]; active: Tab; onChange(t: Tab): void; children: React.ReactNode }) {
  const enabled = useIsAppOrStandalone();
  const reduce = useReducedMotion();
  const ref = useRef<HTMLDivElement>(null);
  const idx = tabs.indexOf(active);
  const sw = useSwipe({
    axis: 'x', enabled, ignore: '.snap-row,.scroll-x,pre,[data-no-swipe],input,textarea,video,iframe',
    onMove(dx) {
      const edge = (dx > 0 && idx === 0) || (dx < 0 && idx === tabs.length - 1);
      const x = edge ? dx / 4 : Math.max(-24, Math.min(24, dx / 3));     // резинка, сдвиг ≤ 24 px
      if (!reduce && ref.current) { ref.current.style.transform = `translateX(${x}px)`; ref.current.style.opacity = String(1 - Math.min(Math.abs(x) / 160, .3)); }
    },
    commit: (dx, v) => Math.abs(dx) > window.innerWidth * 0.35 || Math.abs(v) > 0.5,
    onCommit(dir) { const next = tabs[idx - dir]; reset(); if (next) { haptic('selection'); onChange(next); } },
    onCancel() { reset(); },
  });
  const reset = () => { if (ref.current) { ref.current.style.transform = ''; ref.current.style.opacity = ''; } };
  return <div ref={ref} {...sw} style={{ ...sw.style, transition: reduce ? undefined : 'transform .16s, opacity .16s' }}>{children}</div>;
}
```
`onChange` → `switchTab(tab)` из C-P0-1 (`replaceState`). Строка диалога (CG3) — тот же `useSwipe` с `translateX(clamp(dx,-144,0))`, под строкой две кнопки по 72 px; `data-no-swipe` на самом диалоге в открытом состоянии не нужен, т. к. CG2 стартует только у левого края (≥ 24 px) и не конфликтует.
**Приёмка (жесты).** Проверка пальцем на телефоне и синтетически: (1) в `vv-app` свайп по Ленте меняет раздел и не выходит из сайта; в обычной вкладке не срабатывает; (2) вертикальный скролл не сдвигает контент; (3) жест по `.snap-row`, карусели книг и карте банка не меняет раздел; (4) при `prefers-reduced-motion` смена без сдвига; (5) у самого края (< 24 px) — системная «Назад»; (6) CG3: короткий свайп показывает кнопки, полный — удаляет с «Отменить».

## 10. Что не проверено и ограничения
- **Экран диалога, экран группы, «Новая группа» после создания** — не открывались (создание группы требует реального участника; открывать переписку с реальным человеком не стал). Все пункты по диалогу — **по коду** (C-M-5): Enter без `isComposing`, 14 px, `20rem`, нет long-press/ответа/реакций, опрос 8 с. Что Enter на телефоне отправляет сообщение — **вероятный эффект, не измерено**.
- **Публикации в Ленте, комментарии, лайки, «Из круга»** — не нажимались (запись видна всем). Состояние ленты при 0 записей и экран комментариев — не проверены.
- **Развлечения → Смотрельня и Игры, Сервисы → Погода/Новости/Курсы/VPN/Загрузчик (внутренние экраны), Диск (загрузка), Банк (перевод/кредит/«Забрать 100»), Магазин (покупки), «Админ»** — только верхний уровень или вообще не открывались.
- **Производительность анимаций на слабом телефоне — не проверено.** Замер кадров в headless Chrome привязан к vsync (при троттлинге CPU 6× — те же 60 fps во всех режимах) и **ничего не доказывает**. Найденные факты не про FPS: анимации скрытого чата продолжаются, `.orb` уже без `blur` (`filter:none`), в CSS осталось правило `circle-shimmer` (**[проверить]**, используется ли).
- **Поведение при ширине 1024 px** (`md:w-[min(100%,52rem)]` — Круг 832 px поверх чата) — **только по коду**; измерял 768 и 1280.
- **Жесты и клавиатура — синтетика** (CDP-касания), не палец, не TalkBack, не Android-жестовая «Назад». Горизонтальный свайп вправо из Круга выходил из сайта в Chrome; в WebView поведение другое (истории нет) — **проверить на устройстве**.
