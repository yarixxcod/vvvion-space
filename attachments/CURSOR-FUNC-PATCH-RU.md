# VVVion Space — функциональные баги (задачи для Cursor)

## Правила для Cursor
- Сначала найди код по подсказкам grep, прочитай его и только потом меняй.
- Не меняй дизайн, тексты и API-контракты, если в задаче не сказано иначе.
- Одна задача — один коммит с понятным сообщением.
- После каждой задачи проверь критерии приёмки вручную или тестом.
- Если причина бага не там, где указано, опиши найденное в комментарии к коммиту.
- Секреты и ключи не логируй и не коммить.

## P0 — критично

### 1. Большие файлы не загружаются на МегаДиск
**Как воспроизвести:** МегаДиск → загрузить файл на 20 МБ. Прогресс зависает на 5%. Файл на 586 КБ доходит до 100% «ОТПРАВКА» и не появляется в списке. Файлы до ~200 КБ проходят.
**Где искать:** `rg -n "api/mega|upload|ОТПРАВКА|FormData|multipart" src/ server/`, конфиг лимитов тела запроса (vercel.json, `bodyParser`, `maxBodySize`, nginx `client_max_body_size`), таймауты serverless-функции.
**Что сделать:**
- Найти лимит размера тела или таймаут, на котором обрывается запрос. На Vercel тело функции ограничено ~4.5 МБ, поэтому для больших файлов перейти на загрузку напрямую в хранилище по presigned URL или на загрузку частями (chunked/multipart) с финальным commit-запросом.
- Если запрос упал, показать ошибку и убрать файл из очереди, а не оставлять вечный прогресс.
- Если после 100% не пришёл commit, показать «Не удалось сохранить файл» с кнопкой «Повторить».
**Приёмка:** файлы 1, 20 и 100 МБ загружаются, появляются в списке, скачиваются и совпадают по sha256. Ошибка сети показывается сообщением, прогресс не висит.

### 2. Загрузчик видео не скачивает ни одну ссылку
**Как воспроизвести:** Сервисы → Загрузчик → ссылка на YouTube (watch и Shorts), Instagram reel, TikTok. Ответ: «По этой ссылке ролик не открылся» или «Ролик не скачался».
**Где искать:** серверная функция `POST /_serverFn/1b2d1cebe3e5…`, `rg -n "ролик не открылся|Ролик не скачался|yt-dlp|ytdl|cobalt" `.
**Что сделать:**
- Залогировать на сервере реальную ошибку провайдера (код, текст), не отдавая её клиенту целиком.
- Проверить, жив ли используемый метод (yt-dlp, ytdl-core, сторонний API). Обновить библиотеку или API-ключ. YouTube часто требует свежую версию yt-dlp и cookies или PO-token.
- Возвращать корректный HTTP-статус (4xx для плохой ссылки, 502 для отказа провайдера) вместо 200 с ошибкой в теле.
**Приёмка:** публичные YouTube, YouTube Shorts, Instagram reel и TikTok скачиваются. Неверная ссылка даёт понятное сообщение и статус 4xx.

### 3. Банк: «Перевести» активна при пустой, нулевой и слишком большой сумме
**Как воспроизвести:** Банк → Перевод другу → выбрать получателя → оставить сумму пустой, ввести 0 или сумму больше баланса. Кнопка «Перевести» активна.
**Где искать:** `rg -n "Перевести|transfer|Вернуть часть|Списать целиком|repay" src/`.
**Что сделать:**
- На клиенте: кнопка активна только при `0 < сумма <= баланс`. Под полем — подсказка «Недостаточно средств» / «Введите сумму».
- Так же для «Вернуть часть» в кредите: `0 < сумма <= min(остаток долга, баланс)`.
- На сервере: та же проверка обязательна (клиенту не доверять), плюс проверка, что получатель существует и это не сам отправитель. Операция атомарная (транзакция БД), без двойного списания при повторном клике.
**Приёмка:** при неверной сумме кнопка неактивна и видна подсказка. Прямой запрос к API с суммой 0, отрицательной или больше баланса возвращает 400, баланс не меняется. Двойной клик не создаёт двух переводов.

### 4. AI-чат: ошибки провайдеров
**Как воспроизвести:** чат → модель RolePlay → ответ 429 «Провайдер ограничил частоту». Модель DeepSeek-4.1 → 403 «Ключ отклонён или нет доступа».
**Где искать:** `/api/chat`, `rg -n "RolePlay|DeepSeek|429|403" `.
**Что сделать:**
- Проверить ключ и доступ к модели DeepSeek-4.1, проверить точное имя модели у провайдера.
- Для 429 — повтор с экспоненциальной задержкой (1–2 попытки) и/или переключение на запасной ключ или модель.
- Временно скрыть из выбора модели, у которых нет рабочего ключа.
**Приёмка:** каждая модель из списка отвечает на простой промпт или скрыта. При 429 пользователь видит «Попробуйте через минуту», а не сырую ошибку.

## P1 — важно

### 5. Нет отмены загрузки
Добавить кнопку «✕» у каждого файла в очереди, которая вызывает `AbortController.abort()` / `xhr.abort()` и удаляет недокачанный объект на сервере.
**Приёмка:** отмена останавливает запрос (видно в Network), файл не появляется в списке, место не занимается.

### 6. Молчаливые ошибки загрузки
- Пустой файл: API отвечает 400 «Файл пустой или больше 2 ГБ», а в интерфейсе ничего. Показывать текст ошибки сервера в тосте.
- Повторная загрузка файла с тем же именем: сейчас молча получается одна запись. Спрашивать «Заменить / Сохранить обе (имя (1).png) / Отмена» или хотя бы сообщать.
**Приёмка:** на каждый отказ API пользователь видит сообщение. Дубликат не теряет данные молча.

### 7. Мини-плеер держит удалённый трек
После удаления аудиофайла мини-плеер продолжает его показывать, и при каждой загрузке страницы уходят два `GET /api/mega/<id>?view=1` с ответом 404.
**Что сделать:** при удалении файла очищать состояние плеера (и сохранённое в localStorage). При 404 на источник — сбрасывать плеер без повторов.
**Приёмка:** после удаления трека плеер пропадает, в Network нет 404 при перезагрузке.

### 8. «Выбрать все» выделяет лишнее
Сейчас выделяет все файлы, а не только видимые в текущей папке или результатах поиска. Ограничить выделение текущим видом и показывать «Выбрано N».
**Приёмка:** после поиска «Выбрать все» выделяет только найденные.

### 9. Выбор файла на диске попадает во вложения чата
На странице первый `input[type=file]` принадлежит композеру чата, и файлы улетают в `/api/circle-file`. Дать инпутам диска и чата отдельные ref/id и не монтировать инпут чата, когда открыт диск.
**Приёмка:** загрузка на диске не создаёт запросов к `/api/circle-file`.

### 10. Змейка открывается сразу в состоянии «game over»
Сбрасывать состояние игры при монтировании компонента, стартовый экран — «Нажмите, чтобы начать».
**Приёмка:** при каждом открытии игра в начальном состоянии.

### 11. Кнопка отправки активна при пустом вводе
В чате и в Круге кнопка «Отправить» неактивна, если `text.trim() === ''` и нет вложений. Enter при пустом поле ничего не делает.

## P2 — мелочи

### 12. Неверное имя во вложении
Чип вложения для `test.png` показывал `test.jpg`. Брать имя из `file.name`, а не собирать по MIME-типу.

### 13. Плеер короткого аудио показывает 0:00 / 0:00
Для wav длиной 1 с длительность не определяется. Обновлять время по `loadedmetadata` и `durationchange`, использовать `preload="metadata"`.

### 14. Нет тоста при копировании
Для кнопок «Копировать» в чате показывать тост «Скопировано» (как в банке «Номер скопирован»).

### 15. Нет статусов доставки и прочтения в Круге
Добавить в сообщения статусы «отправлено» (✓) и «прочитано» (✓✓), отмечать прочтение при показе сообщения в окне.

### 16. Опечатка в цене VPN
«2000 вублей» → «2000 ₽» или «2000 рублей». `rg -n "вублей" `.

### 17. Галерея картинок на Диске
Нет кнопки загрузки, клик по миниатюре не открывает просмотр. Добавить кнопку загрузки и лайтбокс с кнопкой «Скачать».

## Что работает и трогать не надо
Скачивание с диска (sha256 совпадает), превью txt/png/jpg/mp4/pdf, переименование, запрет дублирующего имени, папки, перемещение, поиск и сортировка, погода, новости, конвертер валют, карта и история в банке.
