# VVVion Space 2.9.1 (versionCode 12) — что сделать на сайте

## Правила для Cursor
- Это **инструкция для сайта** (vvvion.space). Приложение 2.9.1 уже умеет всё описанное ниже; от сайта нужны правки, чтобы APK-«костыли» стали не нужны.
- Не ломать: чат, Круг, уведомления, оплату. Не публиковать и не трогать данные реальных пользователей при проверке; тестовый аккаунт — только B.
- Перед правкой — `rg -n "vvNest|vvCircle|__vvvionHandleBack|pushBackLayer"`; новые слои «Назад» делать **только** через существующие механизмы (ниже), не изобретать второй стек.
- После правок прогнать приёмку (раздел 6) на 390×844 и 1440×900; при любом «Назад», которое выходит из Круга целиком вместо одного шага, — не выкладывать.
- Файлы приложения (`version.json`, APK) выкладывает владелец; код приложения не менять.

## 0. Что проверено на живом сайте (Playwright, 390×844, аккаунт B, 11.11.2026)
- Сайт **уже** реализует: `window.__vvvionHandleBack = () => closeTopLayer()` (чанк `app-back-*.js`, стек `pushBackLayer`), открытие Круга через `pushState` (`/?place=…`, в `history.state` есть `vvCircle:1`), вложенные экраны через `pushState({vvCircle:1, vvNest})` — это сделано для «Новая группа», читалки книг, «Ответы» в Ленте, шторки «Ещё». Для них «Назад» в APK работает правильно (проверено).
- **Не** реализовано: подэкраны внутри раздела, которые переключаются локальным `useState` без истории:
  - **Сервисы → Погода / Новости / Курсы / (VPN, загрузчик)** — компонент `fo()` в `circle-*.js`: `const [t,n]=useState(null)`, подэкран = `t==='weather'|'news'|'fx'|…`, кнопка «‹ Сервисы» делает `n(null)`. История не пишется ⇒ «Назад» закрывает **весь Круг** (это и есть баг пользователя).
  - Банк → форма «Перевод» (встроена в страницу, не подэкран — «Назад» из неё уходит из Круга; допустимо, но лучше тоже слой).
  - Диалог в «Сообщениях» — открыть с реальным человеком не проверял; проверьте тем же способом (должен идти через `vvNest`).
- Вкладки Круга переключаются `replaceState` (`/?place=feed|play|services|disk|bank|shop|chat`) — это правильно (одно «Назад» = выход из Круга в чат).

## 1. Правильное решение для Сервисов (и любых «список → подэкран»)
В кодовой базе есть хук вложенной истории (чанк `stickers-*.js`, ищется по `vvNest`; сигнатура `(open: boolean, onBack: () => void)`): при `open=true` делает `history.pushState({...state, vvCircle:1, vvNest:id})` и регистрирует слой «Назад» (`pushBackLayer(() => history.back())`); при `popstate` вызывает `onBack`; при размонтировании/`open=false` сам откатывает свою запись. Его уже используют читалка, «Новая группа», «Ответы».

Применить к Сервисам:
```tsx
function ServicesPanel() {
  const [sel, setSel] = useState<null | 'weather' | 'news' | 'fx' | 'vpn' | 'grab'>(null);
  useNestedBack(sel !== null, () => setSel(null));      // тот же хук, что у читалки
  if (sel === 'weather') return <Weather onBack={() => setSel(null)} />;   // кнопка «‹ Сервисы» остаётся: setSel(null) → cleanup хука сам делает history.back()
  /* … */
}
```
Аналогично — любой компонент Круга, где есть `useState` «выбранный элемент» и кнопка «‹ …» наверху: Диск (папки, если есть), Магазин (карточка), Банк (форма перевода/кредита), Сообщения (диалог, «Новая группа» уже есть), Развлечения (игра/ролик). Правило: **«экран, у которого есть кнопка `‹` в шапке, обязан быть слоем истории»**.

## 2. Контракт `__vvvionHandleBack` (уже есть; не менять семантику)
```ts
// app-back.ts (существует)
const layers: Array<() => void> = [];
export const pushBackLayer = (close: () => void) => { layers.push(close); return () => { const i = layers.lastIndexOf(close); if (i >= 0) layers.splice(i, 1); }; };
export const closeTopLayer = () => { const c = layers.pop(); if (!c) return false; c(); return true; };   // true = поглотил
window.__vvvionHandleBack = () => closeTopLayer();       // синхронно, быстро; true только если реально что-то закрыли
```
Круг тоже слой: `R(() => history.state?.vvCircle ? history.back() : navigate('/'))` — так и сделано.

## 3. Как APK-фолбэк уступает сайту
APK 2.9.1 при системном «Назад» вызывает `window.__vvBackDispatch()` (мост), порядок:
1. `window.__vvvionBackOwned === true` → **только** сайт (`__vvvionHandleBack`), фолбэк отключён целиком.
2. Открыта шторка/меню/диалог (`[role=dialog|alertdialog|menu|listbox]`, `[aria-modal=true]`, кроме панели Круга) или в `history.state` есть `vvNest` → сначала сайт; если он не поглотил — Escape / кнопка «Закрыть|Отмена|Назад|Готово».
3. Открыт Круг и в шапке есть кнопка `‹` (иконка `lucide-chevron-left|arrow-left` **и** текст/aria-label, выше 170 px; стрелки карусели «Предыдущий/Следующий» игнорируются) → фолбэк кликает её (так Сервисы возвращаются к списку).
4. Иначе — `__vvvionHandleBack` сайта (закрывает Круг/слои); `false` → обычное поведение APK (история WebView / свернуть).
Защита от ловушки: один перехват на одно состояние; если за 400 мс состояние страницы не изменилось — выполняется обычное «Назад» приложения.

**Когда все подэкраны Круга переведены на хук (раздел 1) — добавить в `app-back.ts` одну строку:**
```ts
if (typeof window !== 'undefined') (window as any).__vvvionBackOwned = true;   // APK-фолбэк отключается
```
Не ставить флаг раньше: пока Сервисы не на хуке, флаг вернёт баг (проверено: при `owned=true` из «Курса» Круг закрывается целиком).

## 4. Обновление приложения: поля `version.json`
Диалог обновления теперь в стиле сайта. Поля (все, кроме двух первых, необязательные):
```json
{
  "versionCode": 12,
  "versionName": "2.9.1",
  "apkUrl": "https://vvvion.space/app/vvvion-space-2.9.1.apk",
  "pageUrl": "https://vvvion.space/app/",
  "changes": [
    "Новый диалог обновления в стиле сайта",
    "«Назад» в Круге: из сервиса — в список сервисов",
    "Диалоги сайта (подтверждения) в стиле приложения"
  ],
  "force": false,
  "minVersionCode": 0
}
```
- `changes` — массив строк (до 30; прокручивается, видно ~6). Если нет — берётся `changelog` (строка, **по пункту на строку**; пустые строки и маркеры `-•*` отбрасываются; заголовок вроде «Что нового:» станет пунктом — лучше `changes`).
- `force: true` **или** `minVersionCode > versionCode установленного` → кнопки «Позже» и «Не напоминать» скрыты, диалог нельзя закрыть назад/тапом мимо.
- «Не напоминать об этой версии» запоминает `versionCode`; новая версия покажет диалог снова.
- `pageUrl`/`apkUrl`: хост должен быть `vvvion.space` или `*.vvvion.space` (иначе обновление молча игнорируется).
- **Важно про 2.9.0 → 2.9.1:** обновление предлагает **установленная** версия. Пользователи 2.9.0 увидят **старый серый диалог** (он читает только `changelog` и `force`), новый диалог появится при обновлении с 2.9.1 на следующую версию. Поэтому в `version.json` для 2.9.1 оставьте **и** `changelog` (строка, пункты через `\n`), **и** `changes[]`.
- **Сейчас на сайте** `version.json` = 2.9.0 / versionCode 11 и **`"force": true`**. При выкладке 2.9.1 поставить `versionCode: 12`, `versionName: "2.9.1"`, новый `apkUrl`, и **снять `force`** (или поставить `false`), иначе все пользователи получат неотключаемый диалог.

## 6. Приёмка (в APK-режиме: `window.__vvBackDispatch` — то, что вызывает системная «Назад»)
Эмуляция на Playwright: `/workspace/vvvion/v2/tests-2.9.1/backscen.py (+ backtest.py, lib.py; нужен /workspace/vvvion/captcha/state-b.json из qa_login.py)` (мок `VvvionNative`, инъекция `vv-bridge.js`, реальный залогиненный сайт, аккаунт B). Ожидание после правок сайта (с `__vvvionBackOwned = true`):
- [ ] Чат → Круг → Сервисы → Курс → «Назад» → список сервисов → «Назад» → чат → «Назад» → выход/сворачивание. То же для Погоды и Новостей.
- [ ] Круг → Лента / Развлечения / Сообщения / Диск / Банк / Магазин → «Назад» → чат (один шаг).
- [ ] Шторка «Ещё»: «Назад» закрывает только шторку.
- [ ] «Новая группа», книга, «Ответы» — «Назад» закрывает подэкран, второе — Круг.
- [ ] Прямая ссылка `/?place=services` → Курс → «Назад» → список → «Назад» → чат.
- [ ] Чат без слоёв: «Назад» не перехватывается; список истории открыт — «Назад» закрывает его.
- [ ] `history.length` не растёт от повторных открытий/закрытий (каждый `push` парный `back`).
- [ ] Ни в одном шаге нет двойного перехвата (одно нажатие — один шаг).
